That is `Tabs`, `TabsList` and `TabsContent`. `TabsTrigger` has no passthrough bag — it renders a
button and a label, so there is no single instance for an unknown prop to land on.

## Pass `defaultValue`

<Callout title="Without one, nothing styles as selected">
Lattice's `Tabs.Root` selects the first enabled trigger when it has no value. The [mirrored state](/facet/components/checkbox/#the-state-is-mirrored-not-reached-for) in this file cannot see that decision. It holds `undefined`, so `selected` is false for every trigger. The list renders with nothing highlighted while the content panel switches correctly.

It compiles, it works, and it looks broken. Give `Tabs` a `defaultValue` (or a controlled `value`).
</Callout>

That is the sharp edge of mirroring a private context: a fallback living inside the primitive is
exactly what the mirror was not told.

### `TabsTrigger` and `TabsContent`

`TabsTrigger` takes a required `value`, plus `disabled`, `Text`, `children` and `className`.
`TabsContent` takes a required `value`, plus `children` and `className`.

## The selected state lands on two instances

```tsx
<TabsPrimitive.Trigger
  className={tabsVariants.trigger({
    className: cn(selected && "bg-background", disabled && "opacity-50", props.className),
  })}
>
  <TextSlot className={cn(tabsVariants.triggerLabel(), selected && "text-foreground")}>
```

The surface takes `bg-background`, the label `text-foreground` over its resting
`text-muted-foreground` — two classes on two instances, because nothing inherits.

The state classes sit **inside** the recipe's slot and ahead of `props.className` —
[the one rule](/facet/guides/variants-and-classes/#the-one-rule), since resolution is
last-token-wins.

## `w-fit` on the list, `h-9` on the list

The list hugs its triggers horizontally and states a fixed height, which gives the pill its shape.
`p-1` insets the `h-7` triggers by 4px each side inside the `h-9` track. Changing one number means
changing the other.
